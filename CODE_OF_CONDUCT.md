# Code Of Conduct

Map Daddy aims to be a practical, welcoming project for people building projection mapping tools, art installations, browser renderers, and realtime media systems.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but clarify when something is ambiguous.
- Keep technical criticism focused on the code, design, documentation, or behavior.
- Help make issues and pull requests actionable.
- Respect privacy and do not post secrets, private media, or private deployment details.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Sharing someone else's private information without permission.
- Posting secrets, credentials, private media, or exploit details publicly.
- Repeated off-topic comments that make project work harder.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject pull requests; or block participants when behavior harms the project or community.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
